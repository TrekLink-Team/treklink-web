# Handover note font

`DejaVuSans.ttf`, DejaVu Sans 2.37, is embedded and subset by PDFKit for Vietnamese organization
and signer names. Nest copies this directory into the backend build, so production does not depend
on a font installed on the host. The binary is unchanged; its SHA-256 is
`7da195a74c55bef988d0d48f9508bd5d849425c1770dba5d7bfc6ce9ed848954`.

`LICENSE.txt` preserves the permission and copyright notices embedded in the font. The font may
be redistributed with the application under those terms. The project does not sell it separately.
