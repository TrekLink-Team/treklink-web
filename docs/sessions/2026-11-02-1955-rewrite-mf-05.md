## Findings for the run environment (not code changes)

- `npm run dev` runs the backend with `nest --watch`. The MF-01 handover writes a PDF to `backend/storage`, which
  restarts the backend mid-run ("Reconnecting. Live data is paused."). The runs above started the backend with
  `npm --prefix backend run start`. The same restart can hit the live demo at the handover step.
- A stale root `.env` with `GATEWAY_MQTT_TOPIC_PREFIX="treklink/events/priority"` makes the gateway publish where
  the backend does not subscribe (`treklink/2/json/+/+`); MF-02 then shows "Not heard since handover". The run
  overrode it with `treklink/2/json` and did not touch `.env`.
- A second broker (WSL relay) listens on `::1:1883` and a second Postgres on 5432 on the author's machine. The run
  used `MQTT_BROKER_URL=mqtt://127.0.0.1:1883` and a Postgres on 5433.
- More than one running gateway multiplies the simulated positions; at 6 positions in 60 s the cadence rule of
  incidents REQ-EVT-02 opens `CADENCE_INFERRED` incidents on TL-0009 and TL-0010, which breaks MF-03 step 1 and the
  360 px spec. Stop earlier gateways before a run.
- `DEMO_CONTROLS_ENABLED=true` and `SEED_ORG_API_KEY` are needed for `a11y` on `/t/admin/demo` and MF-04 step 5.
