## Decisions taken here, for review

| Decision | Why |
|---|---|
| `NOT_HEARD` also hides the battery from an organization | a battery reading from before the handover is pre-custody data (D-040) |
| TrekLink staff keep stored values, states computed the same way | the task says staff keep their behaviour plus the states |
| Offline marker violet (`--tl-marker-offline`), not-heard a grey pin (`--tl-marker-unheard`) | D-092 asks a distinct offline colour and a grey pin; shape differs too |
| Marker legend labels: Live, Offline, Not heard since handover, SOS | the stale marker is the offline marker of D-092 |
| MSG41 and MSG42 numbered here | the SRS message catalog lives outside this repository |
| One pin per unit at the counter, stacked | the list carries the count; a grouped pin is a follow-up |
| A heard unit is `LIVE` or `OFFLINE` from `lastSeenAt >= handedOverAt`, no attribution margin | the custody interval starts at the handover; the margin is gateway-sync's attribution rule |
