## 5. Demo click path that works now

Before the demo: migrate, `seed:demo`, start Mosquitto, backend and frontend, then wait at least
5 minutes after seeding before any SOS, or the SOS opens an UNROUTED incident and later SOS packets
from that unit join it. Do not refresh the browser: the session is held in memory and a reload signs out.

1. MF-01, `manager@`: Contracts, Request a contract, Monthly, treklink-v3, 5, start today, Send
   request. `staff@`: Contracts, Requested, the new code, set Handover appointment, Approve.
   `manager@`: Invoices, the new invoice, Pay with SePay; send the webhook
   (`POST /api/payments/sepay/webhook`, `Authorization: Apikey <SEPAY_WEBHOOK_API_KEY>`, `content`
   holding the TL reference); the page shows the payment received. `staff@`: `/t/counter/<id>`,
   Record provisioning on each unit, battery and GPS fix, Next to Payment, Preview, Sign: choose
   Demo Manager, identity, draw, Complete handover.
2. MF-02: `npm --prefix backend run replay:mqtt -- trek --now --new-ids --interval 2000`, or run the gateway.
3. MF-03, `operator@` on Incidents; `replay:mqtt -- sos --now --new-ids`; the SOS banner shows;
   open the incident, Acknowledge, Response under way, Add status, Report outcome. `staff@`:
   Incidents, the seeded UNROUTED INC-2026-000001, Report to authorities (agency, reference,
   Reported at), then Authority reports, Record case closed.
4. MF-04: `operator@` Live map, `staff@` Fleet map.
5. MF-05, `manager@`: RC-2026-0002, Give notice. Run `npm --prefix backend run demo:term-end -- RC-2026-0002`.
   `staff@`: `/t/counter/<RC-2026-0002 id>`, scan TL-0017 and TL-0018, Check in, Reset and
   inspection: Record reset, Inspect (Passed, or Failed for the maintenance leg), Close, Close
   contract (the seeded invoice is paid, so no balance is left when notice comes first).
   Maintenance, Complete with cost 0, then the device page, Record intake check. Retire as
   `admin@` from a MAINTENANCE unit with no open record (close it Unrepairable first).
